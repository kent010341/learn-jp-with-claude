# references/ — 優化用文獻庫

這裡放**優化專案時**查過的文獻：每條只有重點摘要與 citation，用來說明規則與排程設計的依據。

## 誰可以讀
- **測驗階段禁止讀取**：出題、作答、回饋，以及 generator／reviewer／analyst subagent 都不讀這裡。
  規則已經把結論寫成可執行的條文（`rules/`、`tools/jl.py`），測驗時不需要文獻。
- 只有在優化專案（改規則、改排程、評估設計、回應使用者對方法的質疑）時才讀。
- 本目錄不在任何必讀清單裡。

## 怎麼寫
- 優化時新查的文獻，**append** 到對應主題檔的最後；不重寫、不刪除舊條目。結論被推翻時，新增一條說明，並在舊條目加一行「見 #n」。
- **不放論文全文或大段原文**：只寫自己整理的重點，引用原文最多一句。
- 只寫查證過的內容；書目細節（卷期、頁碼、標題）沒查證到就標「待查證」，不要補猜。
- 每條格式：

```
### n. 作者（年份）— 一行主題
- citation：作者. (年份). 標題. 期刊/出處, 卷(期), 頁. DOI 或 URL
- 重點：2–3 行，用自己的話
- 本專案怎麼用：對應哪條規則或排程設計
- 限制／爭議：適用範圍、反面結果
```
