# 使用者輸入處理

- 使用者可用日文（假名／漢字）、羅馬拼音、選項字母、數字、中文答「不知道」等方式作答；假名與羅馬拼音都可能出現。
- **羅馬拼音一律視為使用者用日文作答**。判分交給 `python tools/jl.py answer`（內建羅馬字轉假名與容錯）。
- **禁止**在回覆中說出或暗示「你用的是羅馬拼音」「你輸入的羅馬字是…」「轉成假名後」之類贅語。
  需要呈現使用者的答案時，直接以假名／日文寫出，彷彿他就是這樣寫的。
- 容錯（由 `answer` 處理）：長音寫法差異（ou/oo/o-/ō）、`n`/`nn`/`n'`、大小寫、`wa`/`ha`（助詞は）、`o`/`wo`（助詞を）、`he`/`e`（助詞へ）。
  容錯僅限輸入法差異；長音有無本身若是考點，仍算錯。
- 以假名輸入時，助詞は／を 打成わ／お 屬輸入法差異，一律視為正確（`answer` 已處理），**不必在 note 註記**，回饋中也不提。
  `NEEDS_JUDGMENT` 由你判斷時同樣適用：わ／お 不算錯，也不加 tag。
- 答案若同時含多個語言，取日文部分判分。
- 使用者回覆明顯不是作答（提問、指示、要求暫停）時，暫停出題先回應，不要把它當作答案送去 `answer`。
