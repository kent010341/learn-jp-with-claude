# 測驗流程

## 原則
1. **先測驗，後講解**。不預先教內容；新項目直接以題目呈現。
2. **每題立即回饋**。答完馬上告知對錯與正解，不延後。
3. **只對答錯／不知道的項目講解**；答對只用一行確認，不長篇稱讚。
4. 永遠提供「不知道」選項（使用者可答「不知道」「?」「idk」）；不知道不算亂猜，視為品質 0 並照常講解。
5. 同一輪題型交錯混合；不要一次問同類型連續多題。
6. 目標是中高答對率而非全對；過易或過難時調整下一輪規格。

## 一題的流程
1. `python tools/jl.py next` 取得下一題（含 id、題型、題幹、選項、可接受答案已在資料庫，不在輸出中洩漏）。
2. 向使用者出題：只呈現題幹（日文附假名）與選項（若為選擇題）。一次一題。
3. 使用者作答後執行 `python tools/jl.py grade <item_id> "<使用者原文>"`，取得判分結果與 `quality`。
   - 若 `grade` 回報 `ambiguous`（無法自動判定），由你判斷並用 `record` 以明確 quality 寫入。
4. 回饋後執行 `python tools/jl.py record <item_id> <quality> --mode <jp|romaji|choice|unknown> --answer "<原文>"`
   （`grade` 輸出的指令範本可直接使用）。
5. 判分 quality：0 不知道／完全錯；1 錯但有接近；2 錯但看得出部分正確；3 勉強答對（遲疑、僅對一部分格式）；4 答對；5 秒答且完整。

## 答錯回饋格式（繁體中文）
- 一行：正解（日文＋假名＋中文意思）。
- 一到兩行：**差異點**——使用者答案和正解差在哪（例如長音有無、助詞は／が、字形相近）。聚焦差異，不展開整段文法講義。
- 如有，附一個**真實場景片段**（符合 content-policy）。
- 不批評、不泛泛打氣；簡短。

## 回合結構
- 一輪約 10–20 題。每輪結束或每約 10 題做 checkpoint（見 compaction.md）。
- 一輪結束報告：答對率、錯最多的類型、下一輪建議；不要逐題重述。
