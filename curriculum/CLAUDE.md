# curriculum/

- `seed/*.json`：被版控的種子題庫，任何人 clone 後第一次執行 `jl.py` 會自動匯入（資料庫為使用者私有，不入版控）。
- 題目格式見 `../tools/CLAUDE.md`；內容規範見 `../rules/content-policy.md`（**必讀**）。
- 新題一律經 generator → reviewer → `import`（`../rules/subagent-policy.md`）。要成為公用種子再複製進 `seed/`。

## 階段（由簡到難；以測驗結果決定實際進入點，不依序硬教）
| stage | 內容 |
|---|---|
| 0 | 安置測驗：假名辨識、極高頻單字、基本助詞、最常見的真實短語。用來探底 |
| 1 | 假名鞏固（含濁音、拗音、長音、促音）、日常最高頻單字與數字、基本助詞（は／が／を／に／で／の／も）、點餐購物招呼語 |
| 2 | 動詞基本形與ます形、形容詞、「〜ください／〜はありますか／〜たい」等真實句型、車站與觀光看板用語 |
| 3 | 聊天用語（LINE 式短句、語氣詞、口語縮略）、て形與常見表達 |
| 4+ | 依弱點與興趣延伸；不納入商業/職場 |
**最終目標**：培養語感與構句能力，而非累積單字與文法條目；各階段內容都以真實情境反應與對比辨別為主。
**以使用者自述為準**：若使用者已熟悉某階段內容（例如五十音），相關題目以 `jl.py retire` 退役，直接從更高處開始，不硬走階段表。
階段由 `python tools/jl.py stage <n>` 設定；依據近期答對率與 `consolidated` 比例決定是否前進，並在 checkpoint 說明理由。

## 題庫擴充規範
- 一輪 10–20 題，類型交錯；比例大致：新概念 60%、對先前弱點的再測 40%（有到期題時優先到期題）。
- 每個 unit 盡量同時有理解與產出的題（unit 要兩種 skill 都鞏固才算鞏固），以便驗證不是只會認不會說。
- 題都答對過但未鞏固的 unit（`jl.py variants`）要補新情境變體，避免只是記住那一題的答案。
- 禁教科書句；以真實場景片段為題幹。審題退回的原因要累積成規則補進 `rules/content-policy.md`。
